Tentang Game Hub

Game Hub X - RPL 2 adalah portal game buatan siswa kelas X-RPL 2. Tujuannya sederhana: belajar membuat halaman web yang rapi sambil menghasilkan sesuatu yang benar-benar seru dimainkan.

Game bisa langsung dimainkan lewat browser di laptop, smartphone, atau tablet. Tidak perlu memasang aplikasi, cukup login lalu klik Main.

Siapa yang membuat

Portal ini dibuat oleh seluruh siswa kelas X-RPL 2 untuk pembelajaran Dasar Pengembangan Software & Gim. Game Burung Terbang dibuat oleh Kelompok 4.
